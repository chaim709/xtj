### 查询数据库

```sql
-- 查询事业单位岗位
SELECT * FROM positions 
WHERE year = 2026 AND exam_type = '事业单位'
LIMIT 10;

-- 按城市统计
SELECT city, COUNT(*) as 岗位数, SUM(recruit_count) as 招聘人数
FROM positions
WHERE year = 2026 AND exam_type = '事业单位'
GROUP BY city
ORDER BY SUM(recruit_count) DESC;
```
