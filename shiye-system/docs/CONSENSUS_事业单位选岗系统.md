## 一、明确的需求描述

### 1.1 核心需求
为**2026年安徽省事业单位考生**提供一个独立的、智能化的岗位选择系统，帮助考生：

1. **快速筛选**：在3,344个岗位中快速找到适合的岗位
2. **科学决策**：基于AI算法和数据分析的推荐
3. **提高上岸率**：通过概率预测帮助考生理性选岗
4. **全面了解**：通过可视化掌握全省招聘态势

### 1.2 用户场景

**场景1：小张（本科会计专业，应届生）**
- 问题：不知道报哪个单位，担心竞争太激烈
- 解决：使用智能选岗向导 → 输入条件 → 系统推荐稳妥型岗位
- 结果：找到3个上岸概率80%+的岗位

**场景2：小李（研究生计算机专业，往届）**
- 问题：想了解省直和各地市的差异
- 解决：查看数据仪表盘 → 16地市对比 → 了解竞争态势
- 结果：选择性价比高的淮北市

**场景3：小王（专科护理专业）**
- 问题：专科岗位太少，不知道还有哪些机会
- 解决：岗位搜索 → 筛选学历"大专及以上" → 发现基层卫生院机会
- 结果：找到60+个护理岗位

## 二、技术实现方案

### 2.1 系统架构

```
┌─────────────────┐
│   Web浏览器      │
└────────┬────────┘
         │ HTTP
┌────────┴────────┐
│  Flask后端       │
│  ├─ 路由层       │
│  ├─ 服务层       │
│  ├─ 模型层       │
│  └─ 算法层       │
└────────┬────────┘
         │ SQL
┌────────┴────────┐
│  SQLite数据库    │
│  3,344个岗位     │
└─────────────────┘
```

### 2.2 核心技术

- **后端**: Python 3.11 + Flask 2.3
- **数据库**: SQLite（开发）
- **前端**: Tailwind CSS + Alpine.js
- **图表**: ECharts 5.4
- **算法**: 多因子推荐模型

### 2.3 推荐算法

```python
综合评分 = 上岸概率(30%) + 待遇(25%) + 发展(20%) 
          + 生活质量(15%) + 综合评价(10%)

上岸概率 = 基础概率 × 学历系数 × 专业系数 × 分数系数 × 地域系数
```
