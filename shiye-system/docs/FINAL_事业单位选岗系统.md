### 核心算法

**推荐算法** (recommend_service.py):
```python
# 综合评分公式
score = landing_prob(30%) + salary(25%) + development(20%) 
        + life_quality(15%) + overall(10%)

# 上岸概率公式
probability = base_prob × edu_coef × major_coef × score_coef × local_coef
```

**数据分析** (analysis_service.py):
- 薪资预估模型
- 竞争比预估模型
- 难度等级计算

**竞争力评估** (competitiveness_service.py):
- 5维度评分
- 优劣势分析
- 提升建议生成
