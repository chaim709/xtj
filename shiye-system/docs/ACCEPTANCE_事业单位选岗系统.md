## 十一、使用指南

### 11.1 系统启动

```bash
# 1. 进入项目目录
cd /Users/chaim/CodeBuddy/公考项目/shiye-system/backend

# 2. 激活虚拟环境
source venv/bin/activate

# 3. 启动服务
python3 run.py

# 4. 访问系统
# 浏览器打开: http://localhost:5002
```

### 11.2 功能使用

**智能选岗**:
1. 点击"智能选岗向导"
2. 填写学历、专业、分数
3. 选择期望城市
4. 查看推荐结果

**岗位搜索**:
1. 点击"岗位查询"
2. 设置筛选条件
3. 浏览搜索结果
4. 点击详情查看分析

**数据分析**:
1. 点击"数据分析"
2. 查看各类统计图表
3. 了解整体招聘态势

**地市对比**:
1. 点击"地市对比"
2. 查看16地市对比表
3. 根据性价比选择

### 11.3 常见问题

**Q1**: 没有找到匹配的岗位？
- A: 尝试放宽地域条件，或勾选"专业不限"岗位

**Q2**: 推荐的岗位太少？
- A: 降低期望城市限制，考虑基层岗位

**Q3**: 上岸概率如何理解？
- A: 基于历年数据和多因子模型计算，仅供参考

**Q4**: 预估薪资准确吗？
- A: 基于地市平均水平估算，具体以录用通知为准
