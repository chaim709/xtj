## 🎨 核心算法

### 1. 智能推荐算法

```python
综合评分 = Σ(维度分数 × 权重)

= 上岸概率 × 30%    # 最重要
+ 待遇水平 × 25%    # 薪资福利
+ 发展空间 × 20%    # 晋升机会
+ 生活质量 × 15%    # 房价配套
+ 综合评价 × 10%    # 整体评价
```

### 2. 上岸概率模型

```python
上岸概率 = 基础概率 × 学历系数 × 专业系数 × 分数系数 × 地域系数

其中：
基础概率 = 1 / 预估竞争比

学历系数 = {
    博士: 3.0     # 几乎无竞争
    研究生: 1.8   # 竞争适中
    本科: 1.0     # 基准
    专科: 0.7     # 竞争激烈
}

专业系数 = {
    精确匹配: 1.5   # 专业完全对口
    大类匹配: 1.2   # 专业大类匹配
    相关专业: 1.0   # 相关专业
    不限专业: 0.8   # 专业不限（竞争大）
}

分数系数 = f(用户分数 - 历年最低分)
地域系数 = 本地1.3, 外地1.0
```

### 3. 竞争比预估模型

```python
预估竞争比 = 城市基础竞争比 × 学历调整 × 专业调整 × 人数调整 × 层级调整

调整系数：
- 博士: ×0.05
- 仅限研究生: ×0.35
- 专业不限: ×1.8
- 招5人以上: ×0.9
- 省直: ×1.3
- 基层: ×0.5
```
