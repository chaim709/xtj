## 概述

本次集成将**2026年安徽省事业单位招聘数据分析报告**的洞察整合到智能选岗系统中，实现数据驱动的岗位推荐。

### 核心价值

- ✅ **智能分析**：自动计算岗位竞争度、性价比
- ✅ **个性化推荐**：基于学员条件智能推荐岗位
- ✅ **分层推荐**：冲刺/稳妥/保底三档分类
- ✅ **数据驱动**：基于3,443个真实岗位数据

### 数据范围

- **岗位数量**：3,443个
- **招聘人数**：4,221人
- **覆盖地市**：安徽省16个地市 + 省直
- **数据准确率**：98.90%
- **考试类型**：事业单位

---

## 功能特性

### 1. 岗位分析服务

提供岗位的多维度数据分析：

- **竞争度预测**：基于招录人数、学历、专业限制等预测竞争激烈程度
- **性价比评估**：综合竞争度、地域发展、单位等级评估岗位性价比
- **地市评级**：16个地市的发展评级（1-10分）
- **综合建议**：生成针对性的报考建议

### 2. 智能推荐服务

为学员提供个性化岗位推荐：

- **条件匹配**：自动筛选符合学员条件的岗位
- **推荐分数**：综合多维度计算推荐指数
- **分层推荐**：冲刺岗位、稳妥岗位、保底岗位
- **推荐策略**：支持激进/平衡/保守三种策略

### 3. API接口

提供完整的RESTful API：

- `/api/positions/analysis/<id>` - 岗位详细分析
- `/api/positions/recommend/<student_id>` - 智能推荐
- `/api/positions/competition-predict/<id>` - 竞争度预测
- `/api/positions/value-evaluate/<id>` - 性价比评估
- `/api/positions/city-ratings` - 城市评级

## 核心算法说明

### 1. 竞争度预测算法

**公式**:
```
竞争度分数 = 招录人数分(40%) + 学历要求分(30%) + 专业限制分(20%) + 其他条件分(10%)
```

**评分规则**:

| 维度 | 高分（竞争大） | 低分（竞争小） |
|------|---------------|---------------|
| **招录人数** | 1人=100分 | 10人以上=20分 |
| **学历要求** | 学历不限=90分 | 博士=20分 |
| **专业限制** | 专业不限=100分 | 限制多个专业=40分 |
| **其他条件** | 无特殊要求=100分 | 要求党员+基层=60分 |

**分级标准**:
- **高竞争**（≥70分）：竞争激烈，需充分准备
- **中等竞争**（40-70分）：竞争适中，有一定机会
- **低竞争**（<40分）：竞争较小，上岸机会大

---

### 2. 性价比评估算法

**公式**:
```
性价比分数 = 竞争度反转(40%) + 地域发展(30%) + 单位等级(20%) + 稳定性(10%)
```

**评分规则**:

| 维度 | 说明 | 评分方式 |
|------|------|---------|
| **竞争度反转** | 竞争越低性价比越高 | 100 - 竞争度分数 |
| **地域发展** | 基于城市评级 | 评级×10（1-10分→10-100分） |
| **单位等级** | 基于单位名称推断 | 省级95分、市级75分、县区50分 |
| **稳定性** | 事业单位编制 | 公益一类95分、其他80分 |

**地市评级**:

| 评级 | 地市 | 说明 |
|------|------|------|
| 10分 | 省直、合肥市 | 省会城市，发展最好 |
| 8分 | 芜湖市、马鞍山市、滁州市 | 经济较发达地市 |
| 6分 | 六安市、阜阳市、淮南市、安庆市、蚌埠市、铜陵市 | 一般地市 |
| 4分 | 宿州市、淮北市、黄山市、池州市、宣城市 | 欠发达地市 |

**分级标准**:
- **高性价比**（≥70分）：强烈推荐
- **中等性价比**（40-70分）：推荐
- **低性价比**（<40分）：谨慎选择

---

### 3. 推荐分数算法

**公式**:
```
推荐分数 = 条件匹配度(40%) + 竞争度适配(30%) + 偏好匹配(20%) + 发展前景(10%)
```

**评分规则**:

| 维度 | 说明 | 权重 |
|------|------|------|
| **条件匹配度** | 学历、专业、政治面貌等基础条件匹配 | 40% |
| **竞争度适配** | 竞争度与学员水平的匹配度 | 30% |
| **偏好匹配** | 城市、单位类型等偏好匹配 | 20% |
| **发展前景** | 基于性价比评估 | 10% |

**岗位分类**:

| 类别 | 条件 | 数量占比 | 说明 |
|------|------|----------|------|
| **冲刺岗位** | 竞争度≥60分 | 20% | 高难度、高回报，需充分准备 |
| **稳妥岗位** | 竞争度40-60分 | 50% | 中等难度，推荐重点关注 |
| **保底岗位** | 竞争度<40分 | 30% | 低难度，确保上岸 |

## 常见问题

### Q1: 推荐结果为空怎么办？

**A**: 可能的原因和解决方法：

1. **学员信息不完整**
   - 检查：学历、专业、政治面貌、性别、出生日期
   - 解决：完善学员信息

2. **筛选条件过严**
   - 检查：城市、单位类型、最少招录人数等偏好
   - 解决：放宽筛选条件

3. **数据库无匹配岗位**
   - 检查：year、exam_type参数是否正确
   - 解决：确认数据库中有对应年份和考试类型的岗位

### Q2: 竞争度分数如何理解？

**A**: 竞争度分数范围0-100：

- **0-40分**：低竞争，上岸机会大
- **40-70分**：中等竞争，需要一定准备
- **70-100分**：高竞争，需充分准备

分数越高表示竞争越激烈。

### Q3: 推荐策略有什么区别？

**A**: 三种推荐策略的区别：

| 策略 | 冲刺岗位 | 稳妥岗位 | 保底岗位 | 适用人群 |
|------|----------|----------|----------|----------|
| **aggressive**（激进） | 30% | 40% | 30% | 学习能力强、基础扎实 |
| **balanced**（平衡） | 20% | 50% | 30% | 一般考生（默认） |
| **conservative**（保守） | 10% | 40% | 50% | 基础薄弱、求稳上岸 |

### Q4: 如何调整推荐数量？

**A**: 使用`limit`参数控制推荐总数：

```
/api/positions/recommend/1?limit=30
```

推荐岗位会按照策略比例分配到冲刺/稳妥/保底三类。

### Q5: 城市评级的依据是什么？

**A**: 城市评级基于：

1. **经济发展水平**：GDP、人均收入
2. **地理位置**：省会、沿江城市
3. **发展前景**：产业结构、政策支持

评级每年可能调整，当前基于2026年数据。

### Q6: 如何处理异常？

**A**: 所有API都返回统一格式：

```json
{
    "success": false,
    "error": "错误信息"
}
```

建议在调用时进行错误处理：

```python
try:
    response = requests.get(url)
    data = response.json()
    if not data.get('success'):
        print(f"Error: {data.get('error')}")
except Exception as e:
    print(f"Exception: {str(e)}")
```
