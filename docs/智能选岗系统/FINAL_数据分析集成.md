## 🎯 核心功能

### 1. 岗位分析功能

#### 竞争度预测
**算法公式**:
```
竞争度分数 = 招录人数(40%) + 学历要求(30%) + 专业限制(20%) + 其他条件(10%)
```

**分级标准**:
- 🔴 **高竞争**（≥70分）：竞争激烈，需充分准备
- 🟡 **中等竞争**（40-70分）：竞争适中，有一定机会
- 🟢 **低竞争**（<40分）：竞争较小，上岸机会大

#### 性价比评估
**算法公式**:
```
性价比分数 = 竞争度反转(40%) + 地域发展(30%) + 单位等级(20%) + 稳定性(10%)
```

**分级标准**:
- ⭐⭐⭐ **高性价比**（≥70分）：强烈推荐
- ⭐⭐ **中等性价比**（40-70分）：推荐
- ⭐ **低性价比**（<40分）：谨慎选择

### 2. 智能推荐功能

#### 推荐算法
**算法公式**:
```
推荐分数 = 条件匹配度(40%) + 竞争度适配(30%) + 偏好匹配(20%) + 发展前景(10%)
```

#### 岗位分类
- 🔥 **冲刺岗位**（20%）：高难度、高回报
- 🎯 **稳妥岗位**（50%）：中等难度、推荐报考
- 🛡️ **保底岗位**（30%）：低难度、确保上岸

#### 推荐策略
- **激进策略**：冲刺30% + 稳妥40% + 保底30%
- **平衡策略**（默认）：冲刺20% + 稳妥50% + 保底30%
- **保守策略**：冲刺10% + 稳妥40% + 保底50%
