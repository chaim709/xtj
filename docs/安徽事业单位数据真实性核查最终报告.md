### 2. 核查脚本统计偏低的原因

**核查脚本统计**：
- 总岗位数：2,552个
- 总招聘人数：3,002人

**与数据库差异**：
- 岗位差异：-891个
- 招聘差异：-1,219人

**根本原因**：

#### ① 合并单元格未展开（最主要）

**示例：省直主文件**

原始文件结构：
```
序号 | 主管部门（招聘人数）              | 招聘单位                    | 岗位代码
1    | 安徽省教育厅（50人）            | 安徽卫生健康职业学院          | 3000001
2    |                               | 安徽卫生健康职业学院          | 3000002
3    |                               | 安徽交通职业技术学院          | 3000003
...  |                               | ...                        | ...
32   |                               | 安徽林业职业技术学院          | 3000032
```

- **核查脚本统计**：只看到55个有岗位代码的行
- **实际情况**：主管部门列使用了合并单元格，每个部门下有多个招聘单位
- **数据库处理**：正确展开合并单元格，每个招聘单位独立计数
- **结果**：核查脚本统计71岗，数据库674岗（实际应该是674岗）

#### ② 招聘人数在主管部门列标注

**示例：马鞍山市文件**

```
主管部门（招聘人数）           | 招聘单位              | 招聘人数列
中共含山县委（1）             | 县委党校              | 无此列
                            | 县委党校              | 无此列
```

- **实际情况**：招聘人数标注在主管部门列的括号中，如"（1）"表示该部门招聘1人
- **但实际**：该部门下有多个招聘单位和岗位，总人数远大于1人
- **数据库处理**：根据实际岗位数计算总招聘人数
- **核查脚本**：无法识别这种格式，统计为0人
