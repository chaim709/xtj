## 📖 核心功能使用

### 1️⃣ 智能选岗向导（推荐功能）

**使用场景**: 不知道报哪个岗位，需要系统推荐

**使用步骤**:

```
第1步：学历与专业
├─ 选择学历：专科/本科/研究生/博士
├─ 输入专业：如"计算机科学与技术"
└─ 选择毕业状态：应届/往届/在职

第2步：能力评估
├─ 预估笔试分数：100-180分
├─ 政治面貌：党员/团员/群众
└─ 特殊身份：三支一扶/退役军人等

第3步：地域偏好
├─ 选择期望城市：可多选
└─ 是否愿意去基层

第4步：确认信息
└─ 检查填写的信息是否正确

第5步：查看推荐
├─ 🔴 冲刺型：60-70%概率，优质岗位
├─ 🔵 稳妥型：70-85%概率，主攻方向  
└─ 🟢 保底型：85%+概率，兜底选择
```

**推荐策略**:
- 准备3-5个备选岗位
- 重点关注稳妥型岗位
- 保留1-2个保底岗位
- 报名时根据实时竞争情况调整

---

### 2️⃣ 岗位查询（搜索功能）

**使用场景**: 想找特定单位或满足特定条件的岗位

**筛选条件**:

| 筛选项 | 说明 | 示例 |
|--------|------|------|
| 城市 | 选择目标城市 | 合肥市、六安市 |
| 系统类型 | 教育、医疗等 | 教育系统 |
| 学历要求 | 最低学历 | 本科及以上 |
| 考试类别 | A/B/C/D/E类 | A类-综合管理 |
| 单位名称 | 关键词搜索 | "职业学院" |
| 岗位名称 | 关键词搜索 | "专业技术" |
| 专业 | 专业名称 | "计算机" |

**排序方式**:
- 推荐度（默认）
- 竞争比（从小到大）
- 招录人数（从多到少）
- 预估薪资（从高到低）

**使用技巧**:
- 先大范围搜索，再逐步细化
- 使用多个条件组合筛选
- 注意查看"未明确"学历的岗位
- 善用"专业不限"扩大选择面

## 💡 实用技巧

### 选岗黄金法则

1. **就高不就低**
   - 本科生优先选"仅限本科"
   - 研究生优先选"仅限研究生"
   - 减少低学历竞争者

2. **专业优先原则**
   - 优先选专业对口岗位
   - 避开"专业不限"（竞争大）
   - 谨慎选择专业大类岗位

3. **地域理性选择**
   - 本地考生优势明显
   - 外地考生考虑生活成本
   - 基层岗位机会多但条件艰苦

4. **多手准备策略**
   - 冲刺1-2个理想岗位
   - 主攻3-5个稳妥岗位
   - 保留2-3个保底岗位

5. **分数合理评估**
   - 行测70分+申论65分 = 135分
   - 行测75分+申论70分 = 145分
   - 建议留出5-10分安全边际

### 避雷指南

❌ **不要选的岗位**:
1. "三不限"岗位（专业、学历、户籍都不限）
2. 热门专业+热门单位+省会城市
3. 只招1人的超热门岗位
4. 条件不符还硬报的岗位

⚠️ **谨慎选择的岗位**:
1. 专业要求模糊的岗位（易被刷）
2. 报名人数已经很多的岗位
3. 上岸概率<50%的岗位

✅ **建议选择的岗位**:
1. 专业限制严格的岗位（排除竞争者）
2. 冷门专业+优质单位
3. 基层岗位（如能接受）
4. 定向招聘岗位（如符合条件）

## 🎯 使用建议

### 最佳使用流程

1. **第一阶段：了解全局**（1-2小时）
   - 查看数据仪表盘，了解整体情况
   - 浏览地市对比，了解各地差异
   - 明确自己的目标地区

2. **第二阶段：智能推荐**（30分钟）
   - 使用智能选岗向导
   - 获取系统推荐的岗位列表
   - 记录10-15个意向岗位

3. **第三阶段：深度研究**（2-3小时）
   - 逐个查看岗位详情
   - 分析匹配度和竞争度
   - 缩小到5-8个目标岗位

4. **第四阶段：对比决策**（1小时）
   - 横向对比5个岗位
   - 评估上岸概率
   - 确定最终3-5个报考岗位

5. **第五阶段：持续监控**（报名期间）
   - 关注报名人数变化
   - 灵活调整报考岗位
   - 避开"神仙打架"岗位
