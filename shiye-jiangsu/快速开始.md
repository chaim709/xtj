## 💡 5分钟功能体验

### 体验1: 智能选岗（3分钟）

1. **打开系统**
   ```
   http://localhost:5002
   ```

2. **点击"开始智能选岗"**

3. **填写信息**（示例）：
   - 学历：本科
   - 专业：计算机科学与技术
   - 预估分数：135分
   - 期望城市：合肥市、芜湖市

4. **查看推荐结果**：
   - 🔴 冲刺型：5个优质岗位
   - 🔵 稳妥型：8个性价比岗位
   - 🟢 保底型：3个高概率岗位

5. **点击详情**：
   - 查看完整信息
   - 看匹配度分析
   - 读专家建议

### 体验2: 岗位搜索（2分钟）

1. **点击"岗位查询"**

2. **尝试筛选**：
   - 城市：选择"六安市"
   - 单位：输入"学院"
   - 点击"搜索"

3. **查看结果**：
   - 浏览岗位列表
   - 查看招聘人数、竞争比
   - 点击详情深入了解

### 体验3: 数据分析（1分钟）

1. **点击"数据分析"**

2. **查看图表**：
   - 城市分布柱状图
   - 学历分布饼图
   - 考试类别分布
   - 竞争度分析

3. **点击"地市对比"**：
   - 查看16地市排名
   - 对比竞争度和性价比

## 🆘 遇到问题？

### 无法访问系统

**检查1**: 服务是否运行？
```bash
lsof -i:5002
# 有输出说明在运行
```

**检查2**: 端口是否被占用？
```bash
# 如果5002被占用，修改配置
# backend/.env 中修改 FLASK_PORT=5003
```

**检查3**: 虚拟环境是否激活？
```bash
which python3
# 应该显示 .../shiye-system/backend/venv/bin/python3
```

### 数据为空

**解决方案**：
```bash
# 重新导入数据
python3 scripts/import_positions_simple.py
```

### 图表不显示

**原因**: 可能网络问题导致CDN加载失败

**解决**: 
- 检查网络连接
- 刷新页面
- 或等待CDN加载完成
