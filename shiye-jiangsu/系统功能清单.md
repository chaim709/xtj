## 🎯 核心功能

### 1. 智能选岗向导 ⭐⭐⭐⭐⭐

**功能描述**: AI驱动的个性化岗位推荐系统

**入口**: 首页 → "智能选岗向导" 或 导航栏 → "智能选岗"

**使用流程**:
```
步骤1: 学历与专业
├─ 选择学历：专科/本科/研究生/博士
├─ 输入专业：您的专业名称
└─ 选择毕业状态：应届/往届/在职

步骤2: 能力评估
├─ 预估笔试分数：100-180分
├─ 政治面貌：党员/团员/群众
└─ 特殊身份：三支一扶/退役军人等

步骤3: 地域偏好
├─ 选择期望城市：可多选15个城市
└─ 基层意愿：是否愿意去基层

步骤4: 确认信息
└─ 核对填写信息

步骤5: 查看推荐
├─ 冲刺型岗位（5个）- 上岸概率60-70%
├─ 稳妥型岗位（8个）- 上岸概率70-85%
└─ 保底型岗位（5个）- 上岸概率85%+
```

**核心算法**:
- 综合评分：5维度加权（上岸概率30% + 待遇25% + 发展20% + 生活15% + 评价10%）
- 上岸概率：多因子模型（学历×专业×分数×地域）
- 三档分类：按概率自动分类

**特色**:
- ✨ 3秒智能推荐
- ✨ 千人千面
- ✨ 科学评分
- ✨ 概率预测

### 2. 岗位搜索引擎 ⭐⭐⭐⭐

**功能描述**: 强大的多条件搜索和筛选系统

**入口**: 首页 → "岗位查询" 或 导航栏 → "岗位查询"

**筛选条件**（8个维度）:
```
基础筛选：
├─ 城市：15个城市可选
├─ 系统类型：教育/医疗/综合管理等
├─ 学历要求：专科/本科/研究生/博士
└─ 考试类别：A/B/C/D/E类

关键词搜索：
├─ 单位名称：如"职业学院"
├─ 岗位名称：如"专业技术"
└─ 专业搜索：如"计算机"
```

**排序方式**（4种）:
- 推荐度（默认）
- 竞争比（从小到大）
- 招录人数（从多到少）
- 预估薪资（从高到低）

**展示信息**:
- 单位名称、岗位名称
- 学历要求、专业要求
- 招录人数、竞争比
- 难度等级、操作按钮

**特色**:
- ⚡ 响应快速（<0.3秒）
- 🔍 智能匹配
- 📊 结果准确
- 📱 分页展示

### 3. 岗位详情页 ⭐⭐⭐⭐

**功能描述**: 完整岗位信息 + 智能匹配分析

**入口**: 从岗位列表或推荐结果点击"查看详情"

**展示内容**:

**基本信息**:
- 单位代码、岗位代码
- 系统类型、隶属关系
- 区域名称

**条件要求**:
- 学历要求（重要！）
- 专业要求（仔细核对）
- 其他要求（年龄、政治面貌等）

**核心指标**（4个大卡片）:
- 上岸概率：AI计算
- 招录人数：官方数据
- 竞争比：预估数据
- 预估年薪：基于地市水平

**匹配度分析**:
- 学历匹配：符合/不符合/超过要求
- 专业匹配：精确/大类/相关/不限
- 地域匹配：优先/非优先
- 综合匹配：高度/中等/低

**智能建议**:
- ✅ 优势分析（绿色）
- ⚠️ 注意事项（黄色）
- 💡 专家建议（蓝色）
- ❌ 劣势分析（灰色）

**相似岗位**:
- 同城市5个相似岗位

**特色**:
- 🎯 个性化分析
- 💡 智能建议
- 📊 数据完整
- 🔗 关联推荐

GET /api/city-comparison
- 功能：获取城市对比数据
- 返回：{data: [{city, positions, recruits, ratio, salary, rank}, ...]}

- 🔌 RESTful规范
