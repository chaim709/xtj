## 🐛 Bug修复

### 修复：学历选择交互问题

**问题描述**：
- 智能选岗向导第一步，学历选项无法点击
- 选中后没有高亮显示，用户不知道选了哪个

**修复内容**：
1. ✅ **可点击**: 整个学历卡片区域都可以点击
2. ✅ **高亮显示**: 选中时显示蓝色边框和背景
3. ✅ **勾选图标**: 右上角显示 ✓ 图标
4. ✅ **悬停效果**: 鼠标移上去有视觉反馈

**修复效果对比**：

```
修复前：
┌─────────┐  ┌─────────┐  
│  本科   │  │硕士研究生│  <- 无法点击，无高亮
└─────────┘  └─────────┘

修复后：
┌─────────┐  ┌─────────┐  
│  专科   │  │ ✓ 本科  │  <- 可点击，蓝色高亮
│         │  │ [选中]  │
└─────────┘  └─────────┘
```

**影响页面**: `/wizard/`（智能选岗向导）

## ✨ 新增功能

### 功能1: 官方政策解答页面

**入口**: 导航栏 → "政策解答"（新增菜单）

**内容**：
- 📋 **25个官方问题解答**（来自省委组织部、省人社厅）
- 🗂️ **5大类别分类**：
  - 学历要求（自考/成教/党校等）
  - 应届生认定（24/25年毕业生/服务基层/退役士兵）
  - 专业认定（括号专业/第二专业等）
  - 工作经历（如何计算/是否累计）
  - 加分政策（服务基层加分/申报流程）

**特色功能**：
- ✅ 快速导航锚点
- ✅ 重要时间节点提醒
- ✅ 咨询电话汇总
- ✅ 问答式展示，清晰易懂

**访问地址**: http://localhost:5002/policy/faq

## 🎯 重要政策要点（必读）

### ✅ 好消息

1. **应届生范围扩大**：
   - 2024、2025年毕业未就业的也算应届
   - 服务基层期满2年内算应届
   - 退役2年内算应届

2. **学历认可更广**：
   - 自考、成教、网教都认可
   - 党校学历可以报考
   - 技工院校（技师=本科）

3. **加分政策**：
   - 服务基层人员报非定向岗可加4分
   - 时间：3月28-29日下午申报

### ⚠️ 重要限制

1. **不能报考**：
   - 在读非应届生（含脱产专升本、在读研）
   - 括号内的专业
   - 最低服务年限内的在编人员

2. **重要时间**：
   - ⏰ 工作经历截止：2026年7月31日
   - ⏰ 证书提供截止：2026年12月31日
   - ⏰ 加分申报：3月28-29日（过期作废）
